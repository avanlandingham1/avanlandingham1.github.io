As part of the Commercial Aircraft Advanced Concepts group, I evaluated electrified aircraft propulsion architectures (EAP) for various aircraft size-classes. Existing internal tools could not handle electric and hybrid-electric propulsion architectures. Tool development was iterative and project-specific. This work was done in MATLAB. 

My contributions to this work included: 
* Implementation of a modular propulsion tool for sizing and analysis of hybrid-electric propulsion architectures
    * modular approach to select all-electric, parallel-hybrid, series-hybrid architectures
* Developed flexible mission definition tool for analysis of flight profiles and trajectory optimization
* Led calibration effort to verify consistency with higher-fidelity internal tools

This work was extended to include an NPSS sizing methodology {% cite carter2022integrated %}.
